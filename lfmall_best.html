LFmall BEST

LFmall은 LF(구 LG패션)에서 운영하는 프리미엄 라이프스타일 패션 이커머스 플랫폼입니다.
기존 베스트 페이지는 랭킹 리스트 단일 구조로, 카테고리 필터링과 성별 필터링 외에 다른 기능은 제공하지 못하고 있었습니다.
이를 고객 맥락에 맞는 다수의 큐레이션 구조로 재설계하여, 페이지 내 상품 발견율과 구매 전환율을 향상시키는 것을 목표로
본 프로젝트를 시작하였습니다.

문제 발견

수동 필터에 의존하는 탐색 경험

기존 베스트 페이지에도 연령별·성별 필터가 존재했으나, 단순 인구통계 정보 기반의 필터링에 그쳐 고객의 탐색 행동에 대응하는 랭킹 화면을 제공하지 못하고 있었습니다.

또한 페이지 전체가 균일한 2열 그리드로 구성되어 1위부터 하위 순위까지 시각적 차이가 없었고, 탐색 목적이 "훑어보기"이든 "조건 맞춰 찾기"이든 고객에게 제공되는 경험은 동일한 리스트 스크롤뿐이었습니다.

재방문 시에도 유사한 상품 리스트만 반복 노출되면서 페이지 전체의 유입과 전환율이 지속적으로 하락하였고, 베스트 페이지가 탐색 장치로서의 역할을 충분히 수행하지 못하고 있음을 알 수 있었습니다.

문제 정의

구조, 개인화, 설득력의 3가지 핵심 문제 도출

이러한 현상의 원인을 분석하여 다음 세 가지 핵심 문제를 도출하였습니다.

첫째, 100개 상품이 동일한 그리드에 나열되어 사용자가 선택에 압도되는 선택 과부하 문제.
둘째, 범용 랭킹이 개별 사용자의 취향을 반영하지 못해 탐색 효율이 낮은 개인 관련성 부재 문제.
셋째, 순위라는 단일 지표만으로는 상품을 신뢰하고 구매를 결정하기 어려운 구매 근거 부족 문제.

이 세 가지 문제는 독립적이 아니라 연쇄적으로 작용하여 페이지 유입과 전환율 하락을 심화시키는 구조적 원인으로 판단하였습니다.

가설 수립

탐색 효율과 구매 신뢰도 향상을 위한 가설

가설 1. 선택 과부하 해소

베스트 상품을 하나의 평면적 리스트로 제공하지 않고, 역할이 다른 복수의 섹션으로 분리하면 고객이 자신의 탐색 목적에 맞는 진입점을 빠르게 찾을 수 있을 것이다.

가설 2. 개인 관련성 확보

고객의 성별, 연령, 탐색 이력을 기반으로 개인화 수준을 점진적으로 높여 노출하면, 범용 랭킹 대비 상품 클릭률과 체류 시간이 증가할 것이다.

가설 3. 구매근거 강화

순위 숫자에 더해 실시간 행동 데이터(조회수, 구매수, 순위 변동폭)를 함께 제공하면, 고객의 상품 신뢰도가 높아지고 상세 페이지 전환율이 상승할 것이다.

고객 탐색 여정 분석

고객 유형별 탐색 예상 경로

플로우 A : 큐레이션 탐색형

"뭘 살지 모르겠지만 인기 있는 걸 보고 싶은" 고객

1. 베스트 페이지 진입 → 2. BEST OF BEST 카테고리 선택 → 3. 해당 카테고리 순위별 상품을 좌우 스와이프로 탐색
→ 4. 관심 상품 선택 → 상품 상세 이동

플로우 B : 개인화 반응형

이전 탐색 이력이 있는 재방문 고객

1. 진입 → 2. 스크롤 다운 → 3. "고객님이 눈여겨본 '아이템' BEST" (개인화 추천상품) 섹션 도달
→ 4-1. 캐러셀 내 상품 탭 → 상세 이동 / 4-2. "다른 추천상품 더보기" 탭 → 추천 상품 갱신 재탐색 → 4-1 재진행

플로우 C : 실시간 트렌드 확인형

"지금 뭐가 뜨는지" 확인하려는 목적성 있는 고객

1. 진입 → 2. 스크롤 다운 → 3. "실시간 랭킹 급상승 상품" 섹션 도달 → 4. "급상승" 텍스트 또는 "순위 텍스트" 등 구체적 수치 확인
→ 5. 관심 상품 탭 → 상세 이동

플로우 D : 필터 기반 목적 탐색형

"여성 가방 중 지금 제일 잘 나가는 것을 찾고싶어" 처럼 구체적 의도가 있는 고객

1. 진입 → 2. BEST TOP 100 영역 도달 → 3. 프로모션, 카테고리, 2depth 필터 설정 → 4. 1~10위 상품 탐색 → 5. 하위 순위 상품 탐색
→ 6. 30개 상품마다 추천되는 개인화 상품 탐색 → 7. 상품 탭 → 상세 이동

문제 해결 1 - 가설 1 대응

4개의 섹션 분리 구조로 레이아웃 차별화

기존의 단일 랭킹 리스트를 4개 섹션(BEST OF BEST, 개인화 추천, 실시간 급상승, BEST TOP 100 필터 랭킹)으로 분리하여
고객의 유형별 진입점을 제공하였습니다.

각 섹션의 레이아웃 형태를 의도적으로 다르게 설계하여, 스크롤만으로도 섹션 전환을 인지할 수 있도록 하였습니다.
또한 순위에 따라 레이아웃 자체를 가변(1~10위 2열, 11위~ 3열)으로 디자인하여 상위 상품에 시각적으로 집중되도록 하였습니다.

문제 해결 2 - 가설 2 대응

암묵적 개인화에서 제어 가능한 단계까지 제공

1단계 : 암묵적 개인화

BEST OF BEST의 카테고리 칩이 고객 성별 및 연령대, 시즌 특성에 맞춰 자동 구성되도록 로직을 설계하여, 고객이 인지하지 못하는 수준이지만 맥락에 벗어나지 않도록 탐색 시작점을 개인화하였습니다.

2단계 : 명시적 개인화

"고객님이 눈여겨본 '원피스' BEST" 섹션으로 개인화 적용 중임을 직접 고지하고, "다른 추천상품 더보기" 버튼으로 추천 결과에 대한 통제권을 부여하였습니다.

3단계 : 제어 가능한 개인화

BEST TOP 100 필터에서 성별과 연령대를 프로필 기반으로 기본값 설정하되, 드롭 다운으로 고객이 직접 변경할 수 있도록 하여 개인화의 최종 결정권을 사용자에게 부여하였습니다.

문제 해결 3. - 가설 3 대응

섹션 목적별 사회적 증거 분산 배치

순위 숫자를 모든 섹션의 기본 신뢰 지표로 유지하되, 각 섹션의 성격에 맞는 보조 증거를 선택적으로 배치하여 정보 과부하 없이 구매 근거를 강화하였습니다.

결과

PV +68.3%, 매출 +61.1% 상승

오픈 직전 2개월 대비 오픈 직후 2개월 기준, 일 평균 PV 중앙값이 약 2,600에서 약 4,370으로 68.3% 상승하였고, 같은 기간 매출 중앙값은 61.1% 증가하였습니다.

PV 순증분을 섹션별로 나눠 보면, BEST OF BEST와 개인화 추천 영역에 약 77%가 집중되었습니다. 섹션 분리(가설 1)와 점진적 개인화(가설 2)가 이번 성과의 주요 동인이었다고 볼 수 있었습니다.

다만 사회적 증거 배치(가설 3)의 효과는 현재 데이터로는 개별 기여도를 분리하기 어려워, 정량 정보를 제공한 상품의 CTR이나 상세 페이지 전환율 등 별도 지표를 통한 후속 검증이 필요한 상태입니다.
