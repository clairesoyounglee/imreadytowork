LFmall 베스트 개편

LFmall은 LF(LG Fashion)에서 전개하는 프리미엄 라이프 스타일 패션 이커머스 플랫폼입니다. 기존 베스트 페이지는 단일 랭킹 리스트 구조로, 다양한 카테고리의 상품이 하나의 순위에 혼재되어 있었습니다. 이를 고객 맥락에 맞는 복수의 큐레이션 구조로 재설계하여 페이지 내 상품 발견율과 구매 전환율을 향상시키는 것을 목표로, 본 프로젝트를 시작하였습니다.

문제 발견

수동 필터에 의존하는 탐색 경험

기존 페이지에도 연령별, 성별 드롭다운 필터가 존재했으나 성별 및 연령만으로 필터링되어 고객의 행동에 맞는 랭킹을 대응하지 못하였으며, 페이지 전체가 하나의 균일한 2열 그리드로 구성되어 1위부터 하위 순위까지 시각적 차이가 없어
탐색 목적이 "훑어보기"이든 "조건 맞춰 찾기"이든, 고객에게 제공되는 경험은 동일한 리스트 스크롤뿐이었습니다.
또한 브랜드 베스트 탭은 유입 및 전환율이 높지 않아 고객에게 추가 탐색장치로서의 기능을 충분히 제공하지 못하고 있었습니다.

문제 정의

구조, 개인화, 설득력의 3가지 핵심 문제 도출

첫째, 100개 상품이 동일한 그리드에 나열되면 사용자는 여전히 선택에 압도된다 - 선택 과부하
둘째, 범용 랭킹은 개별 사용자의 취향과 무관하여 탐색 효율이 낮다 - 개인 관련성 부재
셋째, 순위라는 추상적 지표만으로는 상품을 신뢰하고 구매를 결정하기 어렵다 - 구매 근거 부족

이 세 가지 문제는 독립적이 아니라 연쇄적으로 작용하여, 페이지 체류 시간 저하와 이탈률 상승으로 이어질 것으로 정의했습니다.

가설 수립

탐색 효율과 구매 신뢰도 향상을 위한 가설

가설 1.

베스트 상품을 하나의 평면적 리스트로 제공하지 않고, 역할이 다른 복수의 섹션으로 분리하면 사용자가 자신의 탐색 목적에 맞는 진입점을 빠르게 찾을 수 있을 것이다.

가설 2.

사용자의 성별, 연령, 브라우징 이력을 기반으로 개인화 수준을 점진적으로 높여 노출하면, 범용 랭킹 대비 상품 클릭률(CTR)과 체류 시간이 증가할 것이다.

가설 3.

순위 숫자에 더해 실시간 행동 데이터(조회수, 구매수, 순위 변동폭)를 함께 제공하면, 사용자의 상품 신뢰도가 높아지고 상세 페이지 전환율이 상승할 것이다.

고객 탐색 여정 분석

고객 유형별 탐색 예상 경로

플로우 A : 큐레이션 탐색형

"뭘 살지 모르겠지만 인기 있는 걸 보고 싶은" 고객

1. 베스트 페이지 진입 → 2. BEST OF BEST 카테고리 칩 선택 → 3. 해당 카테고리 내 순위별 상품 좌우 스와이프 탐색 → 4. 관심 상품 탭 → 상품 상세 이동

분기: 칩 미선택 시 스크롤 다운 → 개인화 추천 섹션 노출 → 반응 또는 "다른 추천상품 더보기" 탭

플로우 B : 개인화 반응형

이전 브라우징 이력이 있는 재방문 고객

1. 진입 → 2. 스크롤 다운 → 3. "고객님이 눈여겨본 '아이템' BEST" 도달 → 4-1.  캐러셀 내 상품 탭 → 상세 이동 / 4-2. "다른 추천상품 더보기" 탭 → 갱신 → 재탐색

플로우 C : 실시간 트렌드 확인형

"지금 뭐가 뜨는지" 확인하려는 목적성 있는 고객

1. 진입 → 2. 스크롤 다운 → 3. "실시간 랭킹 급상승 상품" 도달 → 4. "급상승" 뱃지 또는 "27▲" 구체적 수치 확인 → 5. 관심 상품 탭 → 상세 이동

플로우 D : 필터 기반 목적 탐색형

"여성 가방 중 지금 제일 잘 나가는 것을 찾고싶어" 처럼 구체적 의도가 있는 고객

1. 진입 → 2. BEST TOP 100 영역 도달 (또는 플로팅 버튼 탭) → 3. 프로모션 필터 선택 → 4. 카테고리 탭 선택 → 5. 세부 조건 조정 → 6. 2열 그리드(1~10위) 탐색 → 7. 스크롤 시 3열 그리드(11위~) 전환 → 8. 상품 탭 → 상세 이동

문제 해결 1 - 가설 1 대응

4개의 섹션 분리 구조로 레이아웃 차별화

기존의 단일 랭킹 리스트를 4개 섹션 (BEST OF BEST 큐레이션, 개인화 추천, 실시간 급상승, BEST TOP 100 필터 랭킹)으로 분리하여 고객의 유형별 진입점을 제공하였으며, 각 섹션에 암묵적 → 명시적 → 제어 가능한 3단계 개인화를 적용하고, 순위, 급상승 뱃지, 실시간 조회수, 구매수 등 4가지 사회적 증거를 섹션 성격에 맞게 분산 배치하였습니다.
또한 각 섹션의 레이아웃 형태를 의도적으로 다르게 설계하여, 스크롤만으로 섹션 전환을 인지할 수 있게 하며 순위에 따라 레이아웃 자체도 가변(1~10위 2열, 11위~ 3열)하여 상위 상품에 시각적으로 집중되도록 하였습니다.

문제 해결 2 - 가설 2 대응

암묵적 개인화에서 제어 가능한 단계까지 제공

1단계 : 암묵적 개인화

BEST OF BEST의 카테고리 칩이 사용자 성별 및 연령대, 시즌 키워드에 맞춰 자동 구성되도록 로직 설계

2단계 : 명시적 개인화

"고객님이 눈여겨본 '원피스' BEST" 섹션으로 개인화 적용 중임을 직접 고지, "다른 추천상품 더보기" 버튼으로 통제권 부여

3단계 : 제어 가능한 개인화

BEST TOP 100 필터의 "여성, 30대" 등 성별, 연령대는 프로필 기반 자동 설정, 드롭 다운으로 고객이 직접 변경 가능

문제 해결 3. - 가설 3 대응

섹션 목적별 사회적 증거 분산 배치

사회적 증거의 유형을 섹션의 성격에 맞게 선택적으로 배치하여 정보 과부하 없이 설득력을 확보하였습니다.

증거 유형 적용 섹션 설득력 확보 메커니즘
순위 숫자 전 섹션 공통 검증된 인기 (Authority)
급상승 뱃지 / 순위 변동 실시간 랭킹 섹션 전용 지금 뜨고 있는 상품 (시의성)
실시간 조회/구매 수 BEST TOP 100 전용 다른 사람이 구매, 확인중 안내 (FOMO)

결과

PV +68.3%, 매출 +61.1% 상승

오픈 직전 2개월 대비 오픈 직후 2개월 기준, 일 평균 PV 중앙값이 약 2,600에서 약 4,370으로 +68.3% 상승하였으며, 같은 기간 매출 중앙값은 +61.1% 증가하였습니다. PV 순증분의 기여 구조를 분석하면, BEST OF BEST, 개인화 추천, 연관상품 영역이 분산 기여하되 순증분의 약 77%가 BEST OF BEST 및 개인화 추천 영역에 집중되어, 섹션 분리(가설 1)와 점진적 개인화(가설 2) 설계가 성과의 핵심 동인이었음을 뒷받침한다고 판단하였습니다.
